# Brand Claims Confidentiality Guide: validate

## Brief

ArcSeal has a dated internal test report showing one installation passed its specified leak test. Public wording approved: “We document test conditions.” Customer name and report images are restricted. No general performance guarantee is approved.

## Request

## Expected behavior

Identify the hypothesis, evidence needed, feasible test, measure, and decision rule. Mark proposed thresholds as hypotheses; do not assert the test has run or silently rewrite foundations.

Score the actual output with [the rubric](../rubric.md). A structural fixture pass is not a behavioral pass.
