# Brand Claims Confidentiality Guide: apply

## Brief

ArcSeal has a dated internal test report showing one installation passed its specified leak test. Public wording approved: “We document test conditions.” Customer name and report images are restricted. No general performance guarantee is approved. Its public website describes inspection services; that description has no separate internal approval record.

## Request

Create a small proof register with usable public wording and restricted-use notes.

## Expected behavior

Use available context without repeating onboarding. Classify the website description as company-published and usable for attributed provisional drafting, without inventing internal approval or calling it measured evidence. Separate claim support from permission; keep channel restrictions and narrow wording explicit.

Score the actual output with [the rubric](../rubric.md). A structural fixture pass is not a behavioral pass.
