# Audience Strategy Playbook: apply

## Brief

Mend Studio offers in-person clothing repair in one city. It can handle 25 jobs weekly. Interviews: commuters want predictable pickup; vintage shoppers want careful repairs. Five recent jobs came from each group. No margins or acquisition data. Budget is $300 for a pilot.

## Request

Choose a starting audience and a feasible validation action.

## Expected behavior

Use available context without repeating onboarding. Compare urgency, reachability, serviceability and unknown economics; use individual buying situations, not enterprise committees.

Score the actual output with [the rubric](../rubric.md). A structural fixture pass is not a behavioral pass.
