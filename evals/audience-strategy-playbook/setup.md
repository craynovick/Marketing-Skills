# Audience Strategy Playbook: setup

## Brief

Mend Studio offers in-person clothing repair in one city. It can handle 25 jobs weekly. Interviews: commuters want predictable pickup; vintage shoppers want careful repairs. Five recent jobs came from each group. No margins or acquisition data. Budget is $300 for a pilot. No reusable brand foundations have been approved.

## Request

Choose a starting audience and a feasible validation action. Work from this brief; label material gaps rather than requiring full onboarding.

## Expected behavior

Use Setup only to resolve missing essentials; the supplied brief permits a provisional result. Ask at most one material question if needed. Compare urgency, reachability, serviceability and unknown economics; use individual buying situations, not enterprise committees.

Score the actual output with [the rubric](../rubric.md). A structural fixture pass is not a behavioral pass.
