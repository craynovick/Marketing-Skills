# Cookbook output contracts

## Conversation

Use concise conversational paragraphs. Small lists are allowed when useful; do not dump the artifact into chat. Describe actual work and meaningful outcomes, not fabricated progress or hidden reasoning.

## Artifact

Use the selected skill's output contract, not a universal brand-playbook template. Produce valid Markdown with exactly one H1. Use headings, lists, tables, and source links where they improve the deliverable. Do not include executable HTML. Return assumptions, open questions, and source URLs through the save tool fields as well as contextual notes in the document where relevant.

## Visible tools

The application renders tool lifecycle states from actual tool calls. Research output includes the canonical website, reviewed page URLs/titles/excerpts, page count, and failed pages. Do not convert page count into an invented confidence percentage. Save output references an immutable draft version. Question output contains one prompt and 2–4 choices; users can always answer in their own words.
