# Cookbook format contracts

## Chat

Plain text only. Keep it concise. Do not use headings, Markdown bullets, or full document content.

## Workspace Markdown

Use valid Markdown with a single H1, clear H2 sections, and short bullets. Claims supported by crawled material may include an HTML comment reference in the form `<!-- evidence: URL -->`. User decisions may be marked `<!-- source: user -->`. Claims needing review may be marked `<!-- verify -->`.

## Research card

Return canonical URL, page count, source links, skipped or failed pages, crawl time, and a 0–1 confidence score.
