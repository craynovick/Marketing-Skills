# Cookbook playbook

1. For a public-site request, gather bounded evidence and label unavailable or conflicting evidence.
2. Draft or revise only the selected skill. Preserve useful content unless the user asks to replace it.
3. Attach evidence references to claims where evidence exists. Mark user decisions and unverified claims distinctly.
4. Emit a compact chat event explaining the change, reason, and relevant evidence. The document itself is updated outside chat.
5. Recover from a failed crawl by offering retry, edit-site, or continue without research. Never silently fabricate evidence.
